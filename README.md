# Lending Credit Score

Research repository for a unified cross-protocol credit scoring framework in DeFi lending. Implements temporal Graph Neural Networks (GNNs) to model borrower activity across Aave and Compound for individual credit-risk and systemic portfolio risk prediction.

## Overview

This repository contains the implementation developed as part of a research project on cross-protocol credit scoring in decentralized finance (DeFi). The proposed framework represents borrowers' activities across multiple lending protocols as a unified temporal graph and evaluates Temporal GNN models against traditional machine learning baselines.
