# Q1-4

## Question

`What is the average number of events per address?`

## Query

```sql
SELECT project, blockchain,
       COUNT(DISTINCT borrower)                                        AS n_borrowers,
       COUNT_IF(transaction_type = 'borrow')                           AS n_borrows,
       ROUND(1.0 * COUNT_IF(transaction_type = 'borrow')
             / NULLIF(COUNT(DISTINCT borrower), 0), 2)                 AS borrows_por_wallet
FROM lending.borrow
WHERE project IN ('aave','compound')
GROUP BY 1, 2
HAVING COUNT(DISTINCT borrower) >= 100
ORDER BY project, borrows_por_wallet DESC
```
