## Query

```sql
SELECT project, blockchain, transaction_type,
       COUNT(*)                  AS n_eventos,
       COUNT(DISTINCT depositor) AS n_depositors,
       MIN(block_time) AS primeiro, MAX(block_time) AS ultimo
FROM lending.supply
WHERE project IN ('aave','compound')
GROUP BY 1, 2, 3
ORDER BY project, n_eventos DESC
```
